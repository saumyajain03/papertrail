# Retrieval-Augmented Generation (RAG) System

This project is a Retrieval-Augmented Generation (RAG) system designed to answer user questions by retrieving and reasoning over uploaded documents. By leveraging transformer embeddings and grounded text generation, the system ensures accurate and context-aware responses.

## Key Features
- **Document Upload**: Users can upload documents to create a custom knowledge base.
- **Intelligent Retrieval**: Retrieves the most relevant information using transformer-based embeddings.
- **Grounded Responses**: Generates accurate answers based on the retrieved content.
